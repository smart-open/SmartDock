## 2. 故障分级与响应（12.13.1，写进合同）

| 级别 | 定义示例 | 响应 | 恢复目标 | 时段 |
|---|---|---|---|---|
| P1 停线 | 主服务起不来、PG 不可写、EDR 杀掉全部子进程 | ≤30 min | ≤4 h（先恢复生产，根因走版本） | 7×24 |
| P2 降级 | 部分设备离线、Outbox 积压 >1 h、报表不可用 | ≤2 h | ≤8 h | 按合同 |
| P3 可用性 | 单页报错、非关键字段异常 | ≤1 工作日 | 下一补丁版 | 5×8 |
| P4 咨询 | 使用问题、新报表、配置调整 | ≤3 工作日 | 排期 | 5×8 |

**P1 恢复三连（顺序执行，先止血）**：
1. `sc query Platform.Host` 确认状态；停止 → `sc start Platform.Host`（多数为瞬态）。
2. 服务反复挂：查 Windows 事件查看器 + `logs\host-*.log` 尾部 200 行；**不要**先动数据库。
3. 发布目录回滚：`sc stop` → 把 `sc binPath` 指向上一版本目录（版本化目录，05 12.2 纪律 ③）→ `sc start`。**回滚优于现场排错**。

## 3. 排障剧本（10.7 七个高频，平台日志位置展开）

日志位置：`<安装目录>\logs\`（host / acquisition / outbox / audit 四类，10.1 分界）。

| 现象 | 先查 | 再查 | 常见根因 |
|---|---|---|---|
| 设备全部离线 | `logs\acquisition-*.log` 连接失败是否集中爆发；`/api/snapshot/summary` total/good | 交换机口/网关 ping；`device` 表 enabled 与 IP | 现场改了设备 IP、网关不通 |
| 单台设备时好时坏 | 该设备重连日志（5.8 退避 1s→30s 封顶） | 质量码 Bad 占比趋势 | 485 终端电阻、地址冲突、线路干扰 |
| 数据不刷新但页面正常 | 快照时间戳是否新鲜（S2.2 口径） | 采集循环日志有无异常停滞 | 采集循环异常、队列满背压 |
| 报工推送失败 | `mes_outbox` status/error；`logs\outbox-*.log` | MES 侧接口通断、Token 有效期 | Token 过期、字段必填缺失；Dead 用 `POST /api/mes/dead/{id}/replay` 重放 |
| 报表超时 | report_run 留痕（status=1 带 error） | 执行计划、时间范围条件 | 缺索引、未加时间条件（模板强制 from/to） |
| 登录失败 | 统一 401（不区分原因，防枚举） | 账号禁用/锁定（DB 查询） | 密码错、账号停用、服务器时钟漂移 |
| License 验签失败 | `GET /api/license` 的 error 字段 | `logs\host-*.log` 搜 LICENSE_INVALID | 文件损坏、换机未重签、公钥不配 |

## 4. 备份与恢复（05 12.4）

每日 02:30 计划任务跑 `08-tools\backup.ps1`（pg_dump -Fc，保留 30 天）。恢复步骤：
1. 停写：`sc stop Platform.Host`。
2. 建空库（演练）或目标库，`08-tools\restore.ps1 -DumpFile <dump>`。
3. 起服务 → 恢复后必做：设备指令对账（Pending/Suspect）+ Outbox 对账 + 审计链校验（05 12.4）。
4. 每季度演练一次，其中一次必须含 `recovery_target_time` PITR（验收 #30）。

## 5. License 导入与到期（02 §13.6）

导入：替换安装目录 `license.lic` → 平台按文件时间戳自动重载（无需重启；`GET /api/license` 验证 loaded=true）。
到期阶段：宽限 0~30 天全功能提示 → 降级 31~90 天（**采集/报警/历史/登录不停**，仅关新增与过账）→ 90 天后其余只读。
**任何阶段不删数据、不停采集**——续费换新 .lic 即恢复。

## 6. 升级窗口

1. 甲方确认停机窗口 → 2. 备份 → 3. `sc stop` → 4. 新版本目录 + `sc binPath` 切换 → 5. `sc start` → 6. 冒烟（快照 Good、Outbox Acked、登录）。
纯托管驱动插件走「排空 + 子进程重启」（4.8.1），影响面单插件；原生 SDK 驱动必须整体重启。
