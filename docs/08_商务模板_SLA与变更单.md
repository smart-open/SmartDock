# 08 商务模板：SLA 条款与需求变更单（SmartDock）

> 依据：05 文档 12.13.1（支持分级）、12.13.3（质保与版本维护）、12.13.4（变更控制五步）。
> 用途：合同附件直接引用；变更单是 12.13.4 步骤 1「当天转单」的载体。

## 1. SLA 条款（合同附件模板）

### 1.1 服务分级

乙方对甲方报障按下表分级响应；级别由乙方值班工程师按「影响面」判定并在响应时告知甲方：

| 级别 | 定义 | 响应时限 | 恢复目标 | 服务时段 |
|---|---|---|---|---|
| P1 停线 | 采集全面中断 / 无法报工 / 数据丢失风险 | ≤30 分钟 | ≤4 小时（先恢复生产：回滚、切只读、备用配置；**根因修复走后续版本，不包含在 4 小时内**） | 7×24 |
| P2 降级 | 部分设备离线 / MES 报文积压 >1 小时 / 报表不可用 | ≤2 小时 | ≤8 小时 | 【7×24 / 5×8 二选一】 |
| P3 可用性 | 单页面报错、非关键字段异常 | ≤1 工作日 | 随下一补丁版本 | 5×8 |
| P4 咨询/需求 | 使用问题、新报表、配置调整 | ≤3 工作日 | 按变更流程排期 | 5×8 |

### 1.2 边界条款（必写）

1. **地理边界**：P1 远程优先；需到场时乙方在甲方通知后 【X】 小时内可达现场（写实际可达值，不承诺即时到场）。
2. **恢复 ≠ 修复**：恢复目标是生产连续性，根因修复交付形式为补丁版本，排期另定。
3. **远程通道**：甲方提供 VPN 或堡垒机账号；乙方平台不主动外连甲方办公网。第三方桌面工具（向日葵/ToDesk 等）在甲方 IT 允许时方可使用，且不作为唯一手段。
4. **数据出网**：诊断包只出脱敏摘要，完整包留现场；导出需甲方授权并留审计。
5. **现场支持人日**：本合同含 【X】 人日现场支持，超出部分按 【Y】 元/人日计（差旅另计）。
6. **免责**：因甲方网络/机房/第三方系统（MES/ERP）变更、未经乙方确认的现场操作导致的故障，响应不计入上述时限。

### 1.3 质保与版本维护（12.13.3）

| 项 | 条款 |
|---|---|
| 质保期 | 上线验收后 12 个月；期内缺陷修复免费 |
| 版本维护 | 只维护最新两个 Minor；Major 提供迁移支持 6 个月 |
| 安全补丁 | 依赖高危 CVE 不受质保期与商务条款限制，按紧急流程当天处理 |
| 升级窗口 | 每次平台/插件升级由甲方确认停机窗口；托管驱动插件热替换影响面单插件 |
| 年度服务费 | 质保期满后按 License 费 【Z】% / 年收取（含版本升级 + SLA 延续） |
